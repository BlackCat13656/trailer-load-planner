# Trailer Load Planner

Full Load Logistics Solutions is a demo company. This project is a trailer load planner built with vanilla JavaScript: add pallets, drag them into a 2x13 or 2x12 trailer grid, and see space and weight update live.

Built by [Ekan Essien-Udoedi](https://github.com/BlackCat13656)

## How to run

```bash
git clone git@github.com:BlackCat13656/trailer-load-planner.git
cd trailer-load-planner
```

Open `index.html` in your browser, or use the Live Server extension in VS Code.
